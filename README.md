## Claude API 按什么方式扣费？

Claude API 的费用核心是 Token。Token 可以理解为模型处理文本时使用的计费单位，输入内容和模型生成的输出内容分别计算。

Anthropic 当前价格页按模型列出输入和输出价格。例如页面展示的模型价格包括：

| 模型 | 输入价格 | 输出价格 | 常见使用方向 |
| --- | ---: | ---: | --- |
| Fable 5.1 | $10 / MTok | $50 / MTok | 长流程智能体、复杂任务 |
| Opus 5.5 | $4 / MTok | $20 / MTok | 复杂编码和高要求工作 |
| Sonnet 5.5 | $2 / MTok | $10 / MTok | 编程、智能体和通用开发 |
| Haiku 4.5 | $1 / MTok | $5 / MTok | 快速处理、成本敏感型任务 |

这里的 MTok 指一百万个 Token。具体价格会随模型版本和官方价格页面变化，实际调用前应检查当前模型名称和价格。

不要只看模型名称判断成本。实际账单还会受到以下因素影响：

- 提交给模型的上下文有多长；
- 每次返回的最大输出 Token 数；
- 是否重复发送相同系统提示词；
- 是否启用 Prompt Caching；
- 是否使用 Web Search、Code Execution 或其他平台功能；
- 是否批量处理请求；
- 是否在高并发下频繁重试。

例如，一个只发送几十字并要求简短分类的请求，消耗可能很低；一个每次都附带数十万字代码仓库的请求，即使只问一句问题，也可能快速消耗余额。

## Claude API 代充和 API 中转站不是一回事

搜索“Claude API 代充”时，常会看到另一类产品：API 中转站。

两者的使用方式不同：

- **API 代充**：余额通常充值到你的 Claude 账户，后续使用官方账户体系和 API 计费逻辑。
- **API 中转**：你把请求发送到第三方服务商的 Base URL，由第三方转发到模型服务，账号、日志、限额和数据处理方式由中转商决定。

如果你要把业务代码放到生产环境，必须确认程序到底连接的是哪个服务。不要看到“Claude API”几个字，就默认对方提供的是官方账户余额充值。

对于涉及客户资料、源代码、订单信息或内部文档的项目，中转服务还需要额外检查数据保留、日志记录、权限控制和服务商稳定性。Anthropic 的数据保留政策也明确区分了 Claude API、消费端 Claude 产品和第三方集成；第三方网站或工具处理的数据不自动适用 Anthropic 的数据保留安排。
